# esp32

ESP32 开发项目仓库，用于存放 ESP32 相关代码和学习资料。

## 目录结构

```
esp32/
├── .gitignore      # Git 忽略规则
├── .vscode/        # VSCode 工作区配置
└── README.md       # 本文件
```

## 常用开发框架

- **Arduino** - 简单易用，适合快速原型
- **ESP-IDF** - 官方框架，功能完整
- **MicroPython** - Python 开发，适合学习

## 使用方式

### 克隆仓库

```bash
git clone https://github.com/MBO2006/esp32.git
```

### 日常同步

```bash
git add .
git commit -m "更新说明"
git push
```

## 开发环境

- VSCode + ESP-IDF 插件
- 或 PlatformIO
